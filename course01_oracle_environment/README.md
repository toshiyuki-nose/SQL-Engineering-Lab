# Course 1 — Oracle Environment

> Build the Oracle environment used throughout SQL-Engineering-Lab.

---

## Overview

Welcome to the first course of **SQL-Engineering-Lab**.

Before writing SQL, you need a reliable database environment.

In this course, you will prepare Oracle Database Free for the rest of the learning journey. You will learn how to connect to the database, understand Oracle's basic architecture, and create your first database objects.

This course focuses on building a solid foundation rather than covering advanced Oracle administration.

By the end of this course, you will have a fully working Oracle learning environment ready for the rest of SQL-Engineering-Lab.

---

# Learning Objectives

After completing this course, you will be able to:

- Explain the basic Oracle Database architecture
- Connect to Oracle Database Free
- Connect to the `FREEPDB1` pluggable database
- Use SQL*Plus and SQL Developer
- Understand Users, Schemas, and Tablespaces
- Create your first database objects
- Execute SQL scripts successfully
